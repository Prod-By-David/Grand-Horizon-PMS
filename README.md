# Grand Horizon PMS - Hotel Management System

Sistema de Gestión Hotelera modular de nivel empresarial con soporte multi-idioma, multi-divisa, control de turnos y roles (Admin, Mañana, Tarde, Noche).

## Estructura del Proyecto
- `src/components/`: Componentes modulares de la interfaz (Sidebar, Topbar, Login, Dashboard, Reservas, Habitaciones, Clientes, Facturación, Configuración, Modales).
- `src/utils/`: Diccionarios de traducción y divisas.
- `src/App.jsx`: Componente principal, enrutamiento de vistas y gestión de estado global.

## Instalación y Ejecución
1. Instalar dependencias: `npm install`
2. Iniciar servidor de desarrollo: `npm start`
